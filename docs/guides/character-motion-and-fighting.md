# 连续动作与打斗制作技术

要做连贯的侧脸转正、转身和打斗，需要同时维持人物外观、身体结构、运动规律和镜头空间关系。下列是可选制作方法，尚未在贾队长录音室案例中实施完整打斗实验。

## 1. 二维逐帧动画

流程：角色多视图→分镜→动态分镜→关键姿势→中间帧→清稿上色→合成。

侧脸转正时，通常需要设计侧脸、四分之三侧脸、接近正脸和正脸等关键角度。具体张数取决于动作时长、风格和拍摄角度。眼睛位置、鼻子轮廓、头发和耳朵的遮挡关系必须随角度变化。

打斗需要蓄力、出招、接触、受击和回收等姿势。中间帧将关键姿势连起来，但动作力度主要来自关键姿势和时间分配。可使用 TVPaint、Toon Boom Harmony、OpenToonz、Krita 或 Clip Studio Paint 等工具，具体功能依版本而异。

适合追求鲜明画风和精确表演的作品；新角度和复杂动作通常需要持续绘制。

## 2. 二维骨骼动画

将角色拆成头、躯干、四肢等部分，用骨骼控制关节；网格变形和权重决定图层如何弯曲。IK（反向运动学）可以通过手脚目标位置求出关节姿态。

配套技术包括：关节处补画、前后遮挡排序、不同角度素材切换、表情切换，以及头发和衣摆的跟随动作。常见工具有 Spine、Moho、Harmony；Live2D 更偏向面部和有限角度的表现。

适合固定角色的说话、唱歌、走路和可复用招式。大幅转身不能只靠一张正面图拉伸，需要侧面、背面或新增姿态。二维骨骼也可以制作复杂动作，代价取决于素材量和绑定设计。

## 3. 三维动画与国风卡通渲染

流程：角色建模→材质→骨骼绑定与蒙皮→动作→头发服装→灯光→渲染→合成。

| 技术 | 作用 |
| --- | --- |
| 骨骼与蒙皮 | 让模型随关节运动，并控制肘膝等部位的变形 |
| IK/FK | 用手脚目标或逐关节旋转控制动作，可按需要切换 |
| 动作捕捉与重定向 | 将真人或其他骨架的运动映射到目标角色，再修整 |
| 接触约束与动画修正 | 处理脚落地、手握兵器、双方接触、打滑和穿插 |
| 布料与头发模拟 | 处理宽袖、长袍、发束的惯性和碰撞 |
| NPR 卡通渲染 | 用描边、分层明暗和风格化材质获得动漫观感 |

可选择 Blender、Maya、Unreal Engine 等工具。模型和绑定完成后，可以反复使用角色和机位。国风宽袖与长发容易穿模，模拟也可能需要缓存、碰撞体和逐镜头修整；物理计算不会自动产生合适的武打表演。

三维也能只充当二维动画参考：先摆动作与机位，再由二维绘制完成最终线条和造型。

## 4. AI 视频生成与混合制作

通过角色参考图、首尾帧、动作参考、姿态或深度等条件生成短镜头。各模型支持的控制方式不同，应先确认具体能力。成片流程通常还需要多次生成、挑选、局部修复和剪辑。

重点检查：转身后是否还是同一张脸；手脚是否完整；兵器是否持续一致；接触与受击是否同步；衣服纹样是否突变；背景和空间是否漂移。

适合短镜头试验和氛围动作。需要严格执行招式、稳定复用角色或长期连续剧情时，要评估重试与修复成本。生成单个精彩镜头不等于建立了可稳定复用的角色动画系统。

## 5. 打斗额外需要哪些设计

1. 动作与空间：明确双方站位、距离、攻击方向、躲避和反击。
2. 重心与发力：脚支撑身体，髋部和肩膀带动四肢，受力后有平衡变化。
3. 接触：拳、兵器和身体在正确时间相遇，对方同步反应。
4. 节奏：蓄力、加速、接触的短暂停顿与回收形成变化。
5. 镜头：用景别和剪辑保持动作可读性，避免切镜让人物位置无故互换。
6. 后期：刀光、烟尘、运动模糊、震动和声音服务于已成立的动作。

补帧只能估计已有画面之间的过渡，不能可靠修复错误肢体或创造正确攻防；慢动作也会放大接触和结构问题。

## 6. 如何选择

| 目标 | 建议起点 | 主要代价 |
| --- | --- | --- |
| 固定角色唱歌，偶尔转头抬手 | 二维骨骼 + 角度与表情素材 | 绑定和补画 |
| 快速验证一个短转身镜头 | AI 图生视频或简单三维测试 | 筛选与一致性修复 |
| 同一角色长期、多机位打斗 | 三维绑定 + 动作制作 + 卡通渲染 | 前期模型、绑定与风格调试 |
| 强烈手绘风格和定制招式 | 二维逐帧，必要时用三维参考 | 持续绘制和动画人力 |

## 7. 建议的首个验证镜头

先制作一个约 3–5 秒的“侧身转正→抬手→放下”镜头，暂时使用固定机位、简单背景和单个角色。

检查脸型与服装一致性、脚底是否滑动、手是否穿过身体、肩肘弯曲是否自然、头发与衣服是否跟随。能稳定完成后，再尝试单人出拳，最后升级到双人接触。

这是建议的验证步骤，不是已完成的测试。声音克隆、字幕和成片编码可以继续复用原流程，动作制作环节单独升级。
