# Pillow 与国风动漫

Pillow 是 Python 图像处理库，能够绘制图形、文字、纹理与透明图层，也能裁切、缩放、调色和合成图片。国风是一组美术设计选择，Pillow 可以表达其中多种风格，但不是自动生成完整动漫表演的系统。

## 适合绘制哪些画面

| 风格 | 适合的实现方法 | 主要工作量 |
| --- | --- | --- |
| 国风像素 | 低分辨率画布、有限配色、像素化放大 | 人物造型与场景细节 |
| 剪纸、皮影 | 剪影、纹样、透明图层 | 关节拆分与遮挡设计 |
| 水墨剪影 | 笔刷纹理、透明叠加、扩散与模糊 | 墨色、笔触与留白控制 |
| Q 版古装 | 几何造型、预绘表情和姿态 | 角色绘制规则与素材数量 |
| 精细国风人物 | 主要处理已有绘画或生成素材 | 发丝、衣褶与面部细节的美术制作 |

## 为什么精美图片不等于连贯动漫

转头时鼻子、眼睛与脸部轮廓发生变化；转身会露出原图没有的衣服背面。缩放或旋转一张正面图无法补出这些结构。

单张画面配合眨眼、张嘴、衣摆轻动和镜头平移，可以成为动态插画。要完成跨步、转身、打斗，需要新增姿态、骨骼、逐帧或三维等技术。

## 在制作流程中的位置

1. 准备风格统一的角色和场景，可来自程序绘制、手绘或图像生成。
2. 将人物拆成合适图层，补齐遮挡区域并准备新角度。
3. 用 Pillow 统一透明背景、画布、尺寸和色彩，输出素材。
4. 用动画工具控制图层、关节、表情和镜头。
5. 用渲染与剪辑工具完成声音、字幕和成片。

Pillow 的逐帧图像合成功能可以服务动画，但角色运动的规律和素材仍需要另行设计。贾队长像素案例的动作由 GSAP 编排，Pillow 负责画图和准备声音驱动数据。
