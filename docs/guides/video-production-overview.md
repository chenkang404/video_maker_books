# 视频制作技术路线总览

视频可以分成声音、视觉素材、动作、时间轴、渲染和验收六个环节。不同作品可以替换其中一环，而复用其他部分。

## 各环节解决什么问题

| 环节 | 输入与输出 | 常见技术 |
| --- | --- | --- |
| 声音 | 文本或音源→对白、歌声和配乐 | TTS、歌声转换、人声分离、混音 |
| 视觉素材 | 设定→角色、场景、道具 | 手绘、Pillow、矢量绘图、图像生成、三维建模 |
| 动作 | 角色素材→连续表演 | 逐帧、二维骨骼、三维绑定、AI 视频生成 |
| 时间轴 | 镜头和音轨→同步编排 | 剪辑、字幕时间码、GSAP 等动画时间轴 |
| 渲染 | 可编辑工程→视频文件 | 浏览器捕帧、二维/三维渲染器、编码与封装 |
| 验收 | 文件与画面声音→可交付结果 | 解码、规格检查、人工看画面与听音 |

TTS 根据文字生成说话声音；歌声转换依赖已有演唱来保留歌词和旋律，两者不能直接等同。图像生成得到的单张人物也不自动具备连续运动能力。

## 生成图接入现有代码成片

2026-11-24 定下的做法：人物长什么样由大模型出图，代码继续负责已有的时间轴、嘴型、镜头和导出。全身照先作为造型，不直接放进成片。贾队长这一版的任务按下面顺序做，前一步的静帧没通过就不做下一步。

1. 锁造型。正面全身、头到脚、黑长袍、白内衣、斜肩带和腰侧枪套都在同一张图里。和剧照对照后，只重出还不对的部分，例如枪套被画成皮包、细胡子缺失。
2. 只拆成片里会动的片。身子含袍子、肩带和枪套，领口留出脖子能插入的重叠；头含脖子；眼皮一层；嘴分闭、小张、大张三张，沿用现有清唱音量分档。抬起的那条手臂拆成上臂、前臂和手，接头处互相压住。下垂的手画在身子上。脚不拆。房间、窗、桌和歌词继续用现有画面。
3. 一次生成一片。同一正面、同一身高比例、透明底，两端多画出一截用来重叠。参考是已通过的全身照和对应剧照。
4. 先叠成一张不动的全身静帧。检查脖子进领口、肩肘腕相连、脚落在地面上。
5. 把颈、肩、肘、腕写成现有工程里的旋转原点。嘴仍由独立清唱音轨驱动，头、眼皮和抬手沿用已有的轻微动作。
6. 先做两三秒小样：眨眼、张嘴、抬一次手，脚底不动。小样通过后再考虑替换 36 秒成片，不在切层阶段重导。

## 三种常见组合

### 像素或剪纸短视频

分层绘图→离散表情与骨骼/关键帧动作→字幕与混音→渲染。适合固定角色说话、唱歌与简单剧情。贾队长案例采用 Pillow、两状态口型、GSAP 和 HyperFrames。

### 国风动态插画

统一角色与背景→拆分头发、衣袖、面部等图层→局部变形、视差与镜头运动→后期合成。适合氛围画面；大幅转身需要新增角度或其他动作方案。贾队长国风鼎香楼版实际用原生 SVG、GSAP 和 HyperFrames 完成了一条慢速唱歌短片，见[该案例项目](../../example/guofeng-dingxiang-lou/README.md)。

### 连贯角色表演

分镜→多视图角色→二维逐帧或骨骼/三维动画→接触与服装处理→特效与声音→渲染。也可用 AI 生成短镜头，但需要检查角色和动作连续性。

## 选型顺序

先确定角色是否反复出现、是否要大角度转身、是否要准确执行某个招式，以及能否接受多次筛选生成结果。然后制作一个短动作测试，再决定长期技术路线。

帧率、分辨率和特效应在动作设计之后评估：高帧率无法纠正重心错误，清晰画面无法弥补角色在转身后变脸。
