# 知识库范围与证据约定

日期：2026-11-19，补充：2026-11-20

本库沉淀实际视频制作经验和技术选型。当前以中文文档为主，先以贾队长录音室案例建立从音源处理到成片渲染的完整介绍，再扩展国风角色动画。

2026-11-20 起，用代码制作视频的交流中产生的结论和值得记录的内容，可直接写入本库。通用技术说明放在 `docs/guides/`，一条片子的说明放在对应的 `example/<案例名>/`。相关测试使用本机 `llm_new` 环境，见维护约定。

实际使用的技术与未来可选技术应明确区分。案例参数依据原制作脚本与记录；通用指南用于解释方法，不能作为已完成对应实验的证明。

知识正文见 [README](../../README.md) 中的阅读入口。本目录不重复保存整篇技术文章。
