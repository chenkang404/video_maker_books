# 贾队长《慌啥子嘛》——赵本山底版

2026-11-18，根据用户反馈“之前《隐形的翅膀》角色感更好，现有《慌啥子嘛》听不出贾队长”重新制作。

## 输入和处理

- 音源：`reference_audio/慌啥子嘛-赵本山-B站音源.m4a`，来源见同名 `.source.json`。
- 使用 htdemucs 分离全曲人声、伴奏，截取 63.8–95.6 秒副歌，共 31.8 秒。
- 参考：`reference_audio/贾队长-单人长参考音频.wav`，约 20.99 秒，与旧《隐形的翅膀》转换文件所标记的参考相同。
- Seed-VC 44.1 kHz F0 模型，20 diffusion steps，CFG 0.8，length 1.0，关闭自动音高调整，固定随机种子 20261118。
- 两组：原调；降低 5 个半音的角色声区候选。后一组伴奏同步降低 5 个半音。
- 模型均使用用户 `llm_new` 环境，在 GPU 1 上运行。缺少的 Seed-VC / Demucs 辅助包从现有 Seed-VC venv 的 site-packages 补充，未安装或升级环境。
- 混音仅使用转换人声与分离伴奏，不主动混回原唱人声；分离伴奏可能仍有算法残留。
- 输出清唱及伴奏 WAV，伴奏另导出 MP3。混音做响度归一化及首尾淡化。

## 诊断

历史文件表明《隐形的翅膀》采用长参考、20 步、CFG 0.8；旧《慌啥子嘛》加强版采用短参考、35 步、CFG 1.25。具体历史调音流程没有完整记录，不能仅凭文件名断言所有参数相同。

RMVPE 对大于 65 Hz 的帧统计：赵本山选段基频中位数约 287.08 Hz；贾队长参考约 193.23 Hz；《隐形的翅膀》转换成品约 191.32 Hz。音高差是需要比较的因素，不能据此证明主观音色问题的全部原因。

CAMPPlus 相似度仅为辅助信号，受歌曲、音域、录音条件影响，不代表概率或人耳认可程度。此次未进行人工听音验收，角色相似度由用户试听确定。

详细参数、音高统计与最终核对见 `work/生成参数.json`、`work/音高分析.json`、`work/核对结果.json`。生成和混音脚本位于本目录，模型及原仓库未修改。

## 最终辅助比对

CAMPPlus 与贾队长长参考 / 《隐形的翅膀》成品的余弦相似度：原调版 0.8242 / 0.8607；降 5 半音版 0.8562 / 0.9054。旧加强版为 0.7602 / 0.8004。建议优先试听降调版，最终角色感尚待用户试听确认。两版 WAV 均为 31.8 秒，样本有限且无满幅削波；导出 MP3 已通过完整解码检查。短对比顺序：旧加强版、新原调版、新降调版，每段约 8 秒，段间 0.65 秒静音。
