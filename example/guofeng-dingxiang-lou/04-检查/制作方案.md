## 建议分镜

| 时间 | 画面 |
| --- | --- |
| 0–4.5 秒 | 茶桌旁人物中近景，黑袍与斜肩带入画，清唱开头一句 |
| 4.5–12.28 秒 | 随伴奏切至鼎香楼室内全景，木梁、窗棂、灯笼与茶具，角色站姿稳定 |
| 12.28–19.76 秒 | 人物中景，唱歌时轻微抬手、眨眼与衣袖跟随 |
| 19.76–27.18 秒 | 偏移中景构图，黑袍和腰侧枪套轮廓清楚，继续演唱 |
| 27.18–36.3 秒 | 回到稍宽景别，末句后放松表情，镜头轻缓结束 |

本版不加入打斗情节。已实现简化嘴形、眨眼、点头、抬手和五段构图；没有真实三维转身或逐音素口型。
