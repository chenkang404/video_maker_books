# 贾队长《慌啥子嘛》国风鼎香楼版

记录日期：2026-11-20
制作状态：2026-11-19 已输出修复闪烁后的成片。2026-11-20 又在源代码里改了人物比例，该改动只有静帧，尚未重导进 MP4。

对应成片：`03-成片/贾队长-慌啥子嘛-国风鼎香楼-修复闪烁版.mp4`
依据：原任务的制作方案、规格、绘图脚本、核看记录，以及与之共用的降调翻唱说明。音频参数的完整表格见 [录音室版案例](../jiaduizhang-recording-room/README.md)。闪烁排查的逐帧数字见 [闪烁修复记录](闪烁修复.md)。本目录里的 `01-音频` 到 `04-检查` 就是这条片子的过程文件。

## 目标与交付

这条片子让贾队长在鼎香楼唱《慌啥子嘛》。用户要求用代码画非像素的古风画面，角色穿黑色长袍，斜挎俗称“王八盒子”的枪套，枪收在套内。不使用图像生成模型，也不把旧像素图放大涂平。

| 成片项目 | 实际规格 |
| --- | --- |
| 画幅 | 9:16 竖屏，1080 × 1920 |
| 帧率 | 24 fps |
| 工程时长 | 36.3 秒 |
| 容器时长 | 36.334 秒 |
| 编码 | H.264 / AAC |
| 画面坐标 | SVG 以 540 × 960 绘制，映射到 1080 × 1920 |
| 最新已导出文件 | 修复闪烁版，872 帧 |

声音沿用录音室版已经认可的降调翻唱，本片没有重唱，也没有改配乐。

## 这条片子和录音室版的关系

两版用的是同一条音轨和同一套歌词时间。差别在画面：

| | 录音室版 | 国风鼎香楼版 |
| --- | --- | --- |
| 场景 | 鼎香楼里的录音室，有耳机和录音设备 | 鼎香楼室内，木梁、匾额、灯笼、格窗、茶桌 |
| 画法 | Pillow 画小尺寸像素图，再像素化放大 | 原生 SVG 贝塞尔曲线、轮廓线和局部渐变 |
| 嘴形 | 两张图切换 | 同一张矢量嘴按音量改变纵向缩放 |
| 渲染故障 | 当次日志为 GPU、4 个 worker | 当次为 GPU、3 个 worker，成片出现周期性缺帧；后改为单进程软件截图 |

## 整条链路

```text
赵本山版歌曲音源 + 贾队长单人长参考
                 │
                 ▼
        Demucs 分离人声和伴奏
                 │
                 ▼
        Seed-VC 换成贾队长音色，人声降 5 个半音
                 │
                 ▼
        FFmpeg 把伴奏降同样的音，并完成混音
                 │
        ┌────────┴─────────┐
        ▼                  ▼
  清唱开场接伴奏          只含清唱的口型驱动音轨
  （成片听到的声音）        （只用来算嘴形）
        │                  │
        │                  ▼
        │            每秒 12 次 RMS
        │                  │
        └────────┬─────────┘
                 ▼
     Python 写出 SVG 场景、人物和 HTML
                 │
                 ▼
        GSAP 编排嘴形、眨眼、点头、抬手和五个镜头
                 │
                 ▼
        HyperFrames 在浏览器里捕帧，封装成 MP4
```

国风版重新做的是绘图、编排和渲染。分离、换声和混音发生在更早的音频任务里，本片只复制成品。

## 音频：本片听到的声音从哪来

### 实际采用的文件

成片音轨是客栈录音室任务里的“清唱开场接伴奏”。嘴形另用同目录的“口型驱动-清唱”，避免鼓点和伴奏被当成张嘴。

这段声音来自 2026-11-18 的“赵本山底版”重做，不是更早的短参考、35 步加强版。录音室版需求记录写明采用已认可的降调翻唱。国风版制作方案再次写明复用该文件，没有要求重唱。

时间结构：

| 时间 | 内容 |
| --- | --- |
| 0–3.95 秒 | 开头一句清唱 |
| 3.95–4.5 秒 | 停顿 |
| 4.5–36.3 秒 | 带伴奏的 31.8 秒副歌，从副歌开头再唱一遍 |

因此带伴奏后第一句会再次出现“慌啥子嘛，慢慢来”。这是编排，不是音轨接错。

### 各技术在这条声音里做什么

下面是这条音轨实际走过的工具。参数、音高统计和相似度表以 [录音室版案例](../jiaduizhang-recording-room/README.md) 为准，这里只说明它们为什么出现在这条片子里。听到的文件在 `01-音频/`。

| 技术 | 作用 | 本片中的边界 |
| --- | --- | --- |
| Demucs `htdemucs` | 把整首歌分成原唱人声和伴奏 | 伴奏里仍可能有分离残留，不能当成绝对干净的乐器轨 |
| Seed-VC | 保留原唱的词、节奏和旋律起伏，把音色朝贾队长的单人参考靠 | 推理，没有为贾队长单独训练一个模型 |
| Whisper 编码器 | 从原唱提取内容特征 | 这里不生成字幕 |
| RMVPE | 提取基频，用来比较声区并做整体降调 | 统计的是大于 65 Hz 的帧，不能单独证明“像不像贾队长” |
| CAMPPlus | 从参考音频提取音色条件，也用来给候选算余弦相似度 | 相似度不是听感概率 |
| DiT / 条件流匹配 | 按内容、音高和音色条件生成声学表示 | 步数和引导强度见录音室案例，不在国风工程里重设 |
| BigVGAN | 把声学表示变成波形 | 输出 44.1 kHz 路径 |
| FFmpeg `rubberband` | 伴奏降低与人声相同的 5 个半音，并保持时长 | 只处理这一条降调候选的伴奏 |
| FFmpeg 混音与响度滤镜 | 人声清理、淡入淡出、与伴奏混合 | 滤镜目标不等于另一次实测响度报告 |
| SoundFile / NumPy | 国风工程读取清唱驱动音轨并计算 RMS | 不重新做换声 |

最终采用的换声设置是：44.1 kHz、带音高条件、20 步、引导强度 0.8、时长比例 1.0、关闭自动音高对齐、人声和伴奏都降 5 个半音、随机种子 20261118。运行环境是用户的 `llm_new`，物理 GPU 1。这些数字来自音频任务记录，国风绘图脚本没有再次传入它们。

工作区里另有 CosyVoice。这条成片的歌声没有用它从文字合成，而是从已有演唱转换而来。

## 画面：代码如何画出国风

### 绘图

`build.py` 用 Python 拼 SVG 路径，不调用图像或视频生成模型。场景和人物是贝塞尔曲线、1–2.5 单位轮廓、局部渐变和衣褶。基础色：黑袍 `#191f22`，皮革 `#76523a`，窗 `#90a9a1`，木梁 `#5d4433`。

场景包括木梁、雕花支撑、鼎香楼匾额、窗外山月与竹影、瓷瓶、挂画、灯笼、茶桌和牡丹。茶汽是路径动画。匾额文字用本地思源宋体，算作布景，不按界面安全区排除。

已交付成片里的人物是瘦长脸、分头、细胡子、黑长袍、棕色斜肩带和腰侧枪套，枪柄露在套外，人物不持枪。脚落在地面上。这是 2026-11-19 导出的造型。2026-11-20 又在同一脚本里把全身改成约 7.5 头身：脖子约 0.3 头长，肩约 2 个头宽，腰窄于肩，胯约 1.2 个头宽。该修改只更新了源代码和静帧，修复闪烁版 MP4 仍是旧造型。

### 嘴形和动作

清唱驱动音轨按每秒 12 次取窗，计算 RMS：

```text
RMS = sqrt(mean(样本²))
```

国风版不是两张嘴的切换。脚本把能量分成几档，写入 GSAP 的纵向缩放：低于 0.021 为闭嘴；向上依次约为 0.48、0.8 和 1.05。每隔若干窗口再把幅度乘 0.3，避免长音一直张着。画面是 24 fps，嘴形数据是 12 Hz，两者不要求逐帧相同。

这仍然不是逐音素口型，没有“啊、哦、衣”的不同嘴型。

其余动作是预设时间轴，不读取音频：

| 动作 | 已交付成片中的做法 |
| --- | --- |
| 眨眼 | 各镜头内固定时间点，闭合约 0.16 秒 |
| 点头 | 头部大约在 −1.0° 到 1.5° 之间往返 |
| 身体 | 小幅度旋转和上下位移 |
| 抬手 | 持开的手围绕肩部大约 ±7° |
| 茶汽 | 独立的上下和透明度循环 |

没有走路、侧面转身或打斗。

### 五个镜头

五个镜头是同一套矢量场景的缩放和平移，不是五段重新生成的视频。

| 时间 | 景别 | 起始缩放约值 |
| --- | --- | --- |
| 0–4.5 秒 | 清唱近景 | 1.32 |
| 4.5–12.28 秒 | 室内全景 | 1.00 |
| 12.28–19.76 秒 | 中景 | 1.20 |
| 19.76–27.18 秒 | 偏移中景 | 1.15 |
| 27.18–36.3 秒 | 稍宽的结束景 | 1.055 |

镜头在各自时长内还有很小的继续缩放。切点是 4.5、12.28、19.76 和 27.18 秒。

字幕 9 句，歌词约 49 px，竖向位置约 1128 px。右上“AI翻唱”标记约在 444 px。初版字幕曾超出平台安全区，核看时上移过。

HTML 放画面和音轨，CSS 放尺寸和字体，GSAP 放时间轴。每个镜头是一个子合成，歌词是单独的字幕轨，所以换景时不用复制歌词。

## 渲染

HyperFrames 0.9.65 在本地浏览器里按时间轴捕帧，再封装成 MP4。绘图阶段用 `llm_new` 的 Python；渲染用本机 Node 启动 HyperFrames。

第一次导出使用 `beginframe` 捕获、硬件 GPU 和 3 个 worker。文件能完整解码，但连续帧里周期性地夹进大块底色和黑块。静态截图看不出来。

修复时没有改 SVG、动作和音轨，只改捕获：完整截图、软件合成、1 个 worker。修复版 872 帧里，大面积缺帧和非切点大幅跳变都是 0。命令、阈值和不能外推的部分写在 [闪烁修复记录](闪烁修复.md)。后续同类导出优先用原工程里的 `render-stable.sh`。本目录 `04-检查/报告/render-stable.sh` 留了一份当时的脚本，其中的本机路径不能在别的机器上直接运行。

## 局限

已交付的国风版能表现固定角色在一个场景里唱歌。它没有逐音素口型、真实转身、跨步和打斗。一把正面矢量图加位移补不出背面和侧面。

2026-11-20 的比例修改把全身收到约 7.5 头身，脖子约 0.3 头长，肩约 2 个头宽。这些还在源代码和静帧里，没有进入 `修复闪烁版.mp4`。

## 可以这样介绍

国风鼎香楼版沿用贾队长《慌啥子嘛》的降调翻唱：Demucs 分离人声和伴奏，Seed-VC 按单人参考换音色并降低 5 个半音，FFmpeg 完成伴奏降调和混音。画面改为 Python 直接写 SVG，用清唱音量驱动简化嘴形，GSAP 编排眨眼、点头、抬手和五个竖屏镜头，HyperFrames 渲染成 MP4。第一次浏览器 GPU 捕获造成周期性缺帧，稳定成片改为单进程软件截图。
